## DOC-005: Docs tree mixes the current roadmap with archives; one review is unindexed

**Evidence**

- **Archive claim is false:** `README.md:190` says "`docs/` — historical planning and code-review records (each marked as archived)". Two files contradict it:
  - `docs/agent/phases.md` is the live roadmap (`README.md:189`, `CLAUDE.md:49`) and has no banner.
  - `docs/code-review-2026-07.md` starts "# Code Review — 2026-07 / Superficial review pass…" with no Archived banner. It is also missing from the `CLAUDE.md:47-53` index, which does list `code-review-2026-06.md` and `cr_1.md`.
- **Open review findings are untracked:** some findings in the 2026-07 review still apply and appear nowhere in the roadmap.
  - Issue 1: a single `sqlite3.Connection` shared across request threads. It still stands: `app.py:26-28` opens one connection with `check_same_thread=False`, and README and the Dockerfile only forbid `--workers`. See GEN-002.
  - Issue 2: cursor typing.
  - The `aiosqlite` nit (`pyproject.toml:23`, see PKG-003).
- **Mixed folders:** current and archived docs share `docs/agent/`, whose name says nothing about status. Code reviews are split between `docs/` and `docs/agent/`.
- **Undiscoverable docs:** README and CLAUDE.md never point to the in-app user docs (`backend/src/thalimage/docs/*.md`, served at `/docs`); only `phases.md:163` mentions them. Nothing references the Emacs helpers (`thalimage-dev.el`, `.dir-locals.el`).
- **Duplicate command lists:** the dev commands appear in both `README.md:158-173` and `CLAUDE.md:13-20`. CLAUDE.md's copy is a subset that lacks the `fe-*` and `lint-fix` targets.

**Proposed layout**

```
README.md                    user/operator entry point; links to everything below
CLAUDE.md                    contributor/agent conventions; links to README for commands
                             instead of duplicating them
docs/
  roadmap.md                 (was docs/agent/phases.md) current roadmap + backlog,
                             present-tense only; open items from reviews tracked here
  archive/
    README.md                one-line index: each file, date, what it was
    reboot.org, mvp-plan.md, todos.md
    reviews/
      2026-04-cr_1.md, 2026-06.md, 2026-07.md   each with an Archived banner
                                                once its open items are copied
                                                into roadmap.md
  review/                    dated full-review runs (this directory)
backend/src/thalimage/docs/  in-app user docs (unchanged location, since it ships
                             with the package); referenced from README "Documentation"
```

**Acceptance**

- The README "Documentation" section lists `docs/roadmap.md`, `docs/archive/`, and the in-app `/docs` pages with their source directory.
- Every file in `docs/archive/` carries an Archived banner, and no file outside it does.
- Every unresolved finding in `code-review-2026-07.md` is either listed in `roadmap.md` or marked resolved in that record.
- CLAUDE.md either has no command list of its own or has one identical to the README's.
